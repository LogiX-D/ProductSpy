# ProductSpy Bug 记录模板

空白模板，不表示已经发现任何新 Bug。一个问题一份记录；分级基于实际影响，不把设备未提供或 AI 未授权虚构成代码缺陷。

## 基本记录

- Bug 编号：____
- 标题（具体触发和影响）：____
- 首次发现日期/时区：____
- 发现来源：真人封闭测试 / 正式 Chrome 人工 / 自动化 / 代码审查 / 其他____
- 匿名测试者：____
- ProductSpy 版本、包 SHA-256、提交编号：____
- Windows OS 构建、Chrome 版本/渠道、显示缩放：____
- 严重程度：P0 / P1 / P2 / P3；理由和实际影响范围：____
- 状态：待复现 / 已复现 / 修复中 / 待复测 / 已关闭 / 环境阻断
- 实际出现次数 / 测试尝试次数：____
- 是否使用真实 Amazon：是 / 否；是否调用真实 AI：未调用 / 有明确授权 / 未知

| 优先级 | 实际判断                                     | 初步处理                                                               |
| ------ | -------------------------------------------- | ---------------------------------------------------------------------- |
| P0     | 数据丢失、安全泄露、当前支持设备无法启动     | 停止受影响路径，保留数据/原包/最小证据；私下通知维护者，不公开敏感材料 |
| P1     | 采集保存、配对、分析、备份恢复等主要流程失败 | 优先复现和修复，说明安全临时绕行或保持阻断                             |
| P2     | 明显交互、布局、提示问题，基本流程可完成     | 记录具体界面和受影响设备，安排修复                                     |
| P3     | 非关键体验优化                               | 保留反馈，避免扩大本阶段功能范围                                       |

正式 Chrome、鼠标、高 DPI、SmartScreen 未测试是「待验收」，不是 Bug 已复现或通过。验证码/地区策略为环境阻断；只有可证实的产品错误才进一步分级。
