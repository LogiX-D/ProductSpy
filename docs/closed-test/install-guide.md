# ProductSpy 0.5.1 封闭测试安装指南

本指南面向不使用开发工具的 Windows 测试者。仅支持 Amazon。无需安装 Node.js、pnpm 或数据库，也无需 AI Key。需要 Windows 10/11 x64、系统 PowerShell 5.1 和正式 Google Chrome 稳定版。实际支持情况须以设备测试结果为准；准备安装指南不代表这些设备已经通过验收。

## 取得正确的测试包

封闭测试版本保持 GitHub Release **草稿**，不公开发布。草稿链接不能作为所有人都能访问的下载页：有相应仓库权限的人可访问，其他已同意参加的测试者由维护者私下提供原始 ZIP 和校验值。不要为了下载测试包公开 Release，也不要使用来历不明的重打包程序。

本轮使用修订版 `ProductSpy-0.5.1-windows-x64.zip`。这个 ZIP 已包含插件；独立的 `ProductSpy-0.5.1-extension.zip` 是同版本插件，选择其中一种来源即可。两者都不是双击 ZIP 自动安装的程序。原 v0.5.0 草稿及原始文件继续保留，不改写、不公开；它不是本轮修复后的测试包。

维护者须随包提供这两个 v0.5.1 文件的 SHA-256 校验清单，并与本轮实际产物报告核对。包没有校验清单、文件名或哈希不匹配时先停止安装并反馈。不能沿用 v0.5.0 的哈希；更不能把变更后的文件冒称同一测试产物。无法自行核对校验值时请维护者协助，不需要为此安装开发环境。

## 1. 完整解压并双击启动

1. 右键便携 ZIP，选择「全部解压缩」，放在长期保留的本机目录。
2. 打开解压后的文件夹，双击 **ProductSpy.cmd**。不要在 ZIP 压缩窗口里运行。
3. 启动器会启动本机工作台并打开浏览器。默认浏览器不是 Chrome 时，在 Chrome 输入 **http://127.0.0.1:3000**。
4. 保持 ProductSpy 启动窗口运行。它包含「打开工作台」「打开插件文件夹」「AI 设置」「打开用户数据」「停止并退出」。

不要求管理员权限。再次双击不会正常启动第二个服务。3000 端口被其他程序占用时，启动器会提示；先退出你认识并有权关闭的占用程序，再重试。不要结束不认识的进程，也不要改为其他端口，当前插件固定使用 3000。

如果 Windows 安全提示、公司脚本策略或杀毒软件阻止运行，记录完整提示和设备信息，先停止该项测试并反馈。不要关闭系统保护、修改组织策略或把未知提示记成安装成功。当前包没有商业代码签名，SmartScreen 和安全提示需要逐台人工核查。

## 2. 在 Chrome 手动安装插件

1. 在启动器点击「打开插件文件夹」，确认文件夹内有 `manifest.json`。
2. 在 Chrome 输入 **chrome://extensions**。
3. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择便携包里的 **extension** 文件夹，不能选择外层程序目录或 ZIP。
5. 在 Chrome 工具栏拼图菜单中固定 ProductSpy。

独立插件 ZIP 需先完整解压，再选择含 `manifest.json` 的文件夹。加载后不要移动或删除插件目录。当前没有 Chrome Web Store 安装链接。源码开发者的 `apps/extension/dist` 与普通用户的 `extension` 不同，普通用户不需要构建源码。

## 3. 完成安全配对

1. 工作台打开「安装与配对」，点击「生成配对码」。
2. 点击 Chrome 工具栏的 ProductSpy，展开「连接设置」。
3. 将码填入「工作台配对码」，点击「连接工作台」。
4. 确认显示「工作台已连接」。

配对码有效 **2 分钟**、仅能使用一次。过期就在工作台重新生成，不用重装。重新配对会撤销旧连接；卸载重装或扩展 ID 变化可能需要重新配对，工作台商品不会因此删除。配对码、令牌和 Cookie 不得出现在反馈、公开截图或 GitHub Issue 中。

## 4. 采集真实 Amazon 商品

1. 打开你能够正常访问的 Amazon 商品详情页，等待标题、图片、价格和当前颜色/尺寸等变体稳定。
2. 点击扩展。首次使用先阅读说明，点击「同意并开始采集」。
3. 逐项核对页面与插件的 ASIN、标题、价格、货币、品牌、图片、卖点、评分和评论数量；视频只有可靠公开 URL 时才会出现。
4. 点击「保存到素材库」，打开工作台「商品库」，进入该商品并刷新页面，确认记录仍然存在。
5. 切换变体后重新检查 ASIN；同一 ASIN 再次保存应更新原记录，不新增重复商品。

价格缺失、无视频等应记录为缺失或不适用，不能自行推测数据。验证码、登录要求、地区限制或反爬导致阻断时，记录限制并停止受阻项，不绕过保护。采集失败可等页面加载后「重新识别」；测试中的失败也应保留记录，不能只统计最后一次成功。

## 5. 使用 Mock 分析和商品管理

在启动器「AI 设置」确认模式为 **mock**，保存后「停止并退出」再启动，使设置生效。已有用户可能已经配置真实 Key，不能仅凭“不填写新 Key”认定当前是演示模式。没有 Key 的默认 `auto` 也会使用 Mock；封闭基础测试明确使用 `mock` 更便于复现。

打开商品详情的「AI 分析」，检查来源为「本机演示」后点击「开始 AI 分析」。测试编辑并保存、局部重新生成、比较历史、恢复版本、单项/整篇复制以及 Markdown/TXT 导出。恢复会创建新版本；Mock 只能验证流程，不能用于评价真实模型质量。

在商品库创建分组和自定义颜色标签，添加商品、组合筛选、排序、多选和批量操作。先用不含私人资料的测试商品练习。删除商品会删除分析与历史；移动或移除关联也会要求确认。先备份，再核对选中数量和操作目标。检查成功/失败数量，部分成功不算全部成功。每次批量最多 500 件，批量管理不会调用 AI。

真实 AI 测试另行授权：必须由用户明确指定可用 Key、模型、请求上限和预算；Key 只填本机启动器，远程服务只使用 HTTPS，每次生成仍需「授权本次调用」。v0.5.1 修复远程 HTTP 可能明文传输 Key 的问题；不要在旧 v0.5.0 包中使用远程 HTTP。接口配置成功不等于模型已获预算授权。这份指南不构成收费请求授权，日常封闭基础测试不需要真实服务。

## 6. 测试断线和安全退出

1. 先确保已保存商品在工作台可刷新查看。
2. 点击启动器「停止并退出」，确认工作台无法继续在线写入。
3. 在 Amazon 页采集另一个非私密测试商品，扩展应提示未同步并暂存本机。
4. 重新启动 ProductSpy，扩展点击「重试同步」。授权失效时先重新配对。
5. 检查原商品和新商品都在，刷新后仍存在。

关闭浏览器标签不会停止工作台；「停止并退出」或关闭启动窗口才会停止本机服务。卸载插件会删除它的本地存储，先同步所有待保存商品。不要把扩展未同步记录当作已经进入工作台的成功保存。

## 7. 备份、恢复与更新

用户资料与程序目录独立，默认在 **%LOCALAPPDATA%\ProductSpy\**。启动器「打开用户数据」可打开：`data` 保存商品、历史、用量和配对资料；`settings` 保存当前 Windows 用户保护的 AI 配置；`logs` 是本机日志，`runtime` 是运行状态。

### 商品 JSON 备份

商品库「导入与备份」可导出全部或所选商品的完整 JSON，包含分析、历史、分组和标签；不包含 AI Key、启动器设置、配对凭据或用量账本。CSV 仅为基本资料，Markdown/TXT 仅为分析内容，不能作为完整恢复文件。

导入 JSON 会先校验和预览，单文件上限 **2,000 件 / 25 MiB**。有重复 ASIN 时，跳过或保留本机资料两种选择都不会覆盖原分析与历史。恢复是合并，不清空当前库；提交前可取消，提交后等待结果。网络中断先刷新核对，不直接重复提交。完整备份超过上限时分批选择导出。

### 完整本机备份和更新

1. 先「停止并退出」。将用户目录复制到你自己的安全位置。至少保留升级前的 `data` 完整副本；不要在服务写入中复制数据文件。
2. 将新版解压到新目录，保留原用户目录和旧包。启动新版，核对商品 ID、ASIN、分析、历史、分组和标签。
3. 在 Chrome 更新插件加载目录或加载新版，必要时重新配对。确认所有待同步记录已保存后再卸载旧扩展。
4. 验证后再删除旧程序目录；删除程序文件夹不会删除独立用户数据。

0.5.1 保持 0.5.0 商品库格式、商品 ID、分组标签、AI 与历史，不要求清空重建。0.5.x 读取 0.4.0 商品数组不会立刻改写；首次成功写入使用新版分组格式。**0.4.0 不能直接读取 0.5.x 已写入的数据**。回退前先备份当前新版数据，停止服务，再使用升级前备份；升级后新增记录不在旧备份中，不能承诺无损回退。请维护者协助恢复，不用删除用户目录试错。回退到 0.5.0 即使能读取同格式数据，也会重新引入已修复的 HTTPS 安全问题，不建议作为日常使用方案。

DPAPI 仅保护 AI 设置，并绑定原 Windows 用户；商品和备份没有应用级加密。换电脑或 Windows 用户需重新配置 Key、重新配对。完整用户目录包含敏感设置、配对和日志，商品 JSON 也可能包含私人选品及人工分析，**都不要上传到公开仓库、Issue 或反馈表**。提交反馈只提供必要的脱敏字段与截图。
