## 2. 安全机制源码核对

| 路径            | 复核结果与边界                                                                                                                                                |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 本机 API        | `server/http.ts` 限定 loopback Host、HTTP、固定 3000 端口；写请求要求 Origin、JSON 和对应客户端标记。工作台会话检查同源 `Sec-Fetch-Site`，会话绑定实际 Host。 |
| 配对            | `server/auth.ts` 使用 120 秒、一次性随机码；令牌绑定 `chrome-extension://` 来源，仅保存 SHA-256，比较使用定时安全函数；配对失败有限流。撤销不删除商品。       |
| CORS / 管理接口 | CORS 无通配来源；扩展预检需配对，配对入口例外只接受扩展来源。分组、批量、导入、导出和收费分析保留工作台认证，配对扩展不能访问管理操作。                       |
| 扩展本机存储    | Background 将存储访问限制到 `TRUSTED_CONTEXTS`；配对消息只接受自身 Popup 来源。商品同步失败时留在本机待同步队列，401 撤销失效令牌而保留待同步资料。           |
| 图片下载        | 只允许明确列出的 Amazon HTTPS 图片 CDN，拒绝凭据、端口和重定向；限制类型、10 MiB 大小和 15 秒超时，并检查图片签名。不是任意 URL 代理。                        |
| AI 设置         | Key 仅由服务端使用；启动器 DPAPI `CurrentUser` 保护本机设置，输入框遮挡 Key。不把 Key 写入程序包或扩展。原版远程 HTTP 缺口为真实 P1，需使用 v0.5.1 修复版。   |

以上是对实际实现的核对，不宣称能抵御控制本机用户、伪造 HTTP 或读取用户磁盘的程序。商品文件没有应用级加密；Windows 文件权限和 DPAPI 的边界已在隐私说明中披露。

## 3. 启动、退出和数据兼容核对

- 启动器使用包内 Node 和当前用户命名互斥锁；端口已占用时拒绝启动，不终止未知监听进程。
- 默认商品目录在 `%LOCALAPPDATA%\ProductSpy\data`，与解压程序目录分离。停止请求包含当前启动 ID；启动器只停止自己启动的服务对象。Wrapper 观察父启动器和停止文件，调用服务的 SIGTERM 清理路径。
- 商品写入经同一路径串行队列，写临时文件后原子改名。读取异常保留原文件，导入重复 ASIN 保留已有资料；批量只在成功落盘后报告成功。
- v0.4.0 数组只读不会被改写，首次成功写入才转换为 schemaVersion 2。v0.5.x 保持同一存储格式。旧程序不识别 schemaVersion 2，**回退 v0.4.0 需要升级前备份**，不能把新版数据文件直接交给旧程序。
- 商品库 JSON 导出只包含商品、分析、历史、分组和标签，不含会话、Key、配对或启动器设置。停止服务后备份整个 `data` 目录会包含配对配置，必须作为私人文件保管。
- 商品库恢复是非破坏性合并；它不能恢复批量删除后又被其他相同 ASIN 资料替代的原记录，也不会替换当前同 ASIN 分析。需要精确回退时，停止服务并保留当前目录，再使用相应完整备份。

本次仅阅读相关代码；实际进程重复启动、退出、端口冲突、断线、崩溃及跨版本数据验收以本阶段主报告为准。

## 4. 检查工具的实际覆盖范围

现有 ZIP 检查覆盖已知私人文件名、常见令牌模式、已配置环境 Key 的逐值匹配、路径 / CRC / 清单哈希。不能仅因正则无命中就宣称识别了任意格式或经编码的秘密；本轮没有发现此类实际泄漏。构建输入限制到 standalone、必要依赖、公开文件、扩展产物、启动器和指南，未复制真实用户数据目录。

应以封闭测试专用的新用户目录运行测试，并在反馈前人工确认日志、截图和导出 JSON。不要将完整浏览器 profile、配对文件、AI 设置或用户商品备份作为公开 Issue 附件。
