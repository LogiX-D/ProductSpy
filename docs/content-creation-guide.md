# AI 模板与内容创作

ProductSpy v0.7.0 在原有商品库、素材和竞品对比上增加独立的模板及营销文本方案。只生成文本，不渲染视频、不自动发布、不自动下载素材。

## 开始创作

1. 启动便携工作台，保留原用户数据目录。通过扩展采集 Amazon 商品，或使用已经保存的商品。
2. 在「AI 模板」查看内置模板，或复制一份再编辑。可以设置名称、用途、分类、标签、收藏、Prompt、输出项目和结构要求。
3. 模板变量使用 `{{product_title}}`、`{{brand}}`、`{{price}}`、`{{currency}}`、`{{bullet_points}}`、`{{description}}`、`{{market}}`、`{{language}}`、`{{platform}}`、`{{duration}}`、`{{style}}`、`{{goal}}`、`{{comparison_conclusions}}`。预览中缺失的资料显示未知；非法或未闭合变量不能保存。变量只进行一次文本替换，不执行脚本、函数或模板嵌套。
4. 进入「内容创作」，选择商品、模板和生成参数，创建一个方案。可选择已保存、已有分析结果的竞品对比；引用保留原商品 URL、ASIN、快照时间和分析版本，不把旧结论变成实时事实。
5. 设置市场、语言、平台、风格、营销目标、5–180 秒的文本目标时长、创意方向和额外要求。API 地址、模型和 Key 仍在 Windows 启动器「配置 AI」中设置，重启生效；Key 不进入网页、模板或扩展。
6. 未配置真实 AI 时显示「本机演示 / Mock」。真实模式每次请求都需要单独确认，可能计费；取消确认不调用模型。请求失败不自动重试，重新操作前检查已保存结果和用量。

## 编辑与版本

每个商品可以保存多份方案；同一模板可以使用不同创意方向。方案保存商品及模板快照，删除原商品或用户模板不会删除已保存内容。

首次生成可以成为当前版本；已有内容的再次生成保存为候选版本。先比较，再明确采用，原有人工修改保留在历史中。单项重新生成保留其他内容，恢复历史会新增版本而非删掉后来的版本。

未保存编辑保留为本浏览器草稿。遇到并发更新或保存失败时，不自动覆盖服务器上的结果；保留草稿、复制或导出，再核对当前版本。浏览器存储不可用、清理网站数据、换浏览器或磁盘故障不属于草稿持久化保证；重要内容应保存并备份。

可以收藏方案并标记「草稿」「待修改」「已完成」。这个状态由用户判断，不是模型质量认证。

## 复制、导出和备份

支持分区和整篇复制、Markdown / TXT / JSON，以及仅包含文本和来源说明的 ZIP 内容包。文件名包含方案或商品信息；ZIP 不会抓取图片、视频或复制受限媒体。导出的内容和模板可能包含你填写的商业资料，请自行控制分享范围。

模板备份与内容方案备份分别导出和导入。导入前检查大小、格式、版本、结构及冲突，重复编号保持已有资料，不默认覆盖人工修改或历史。商品库和竞品对比仍使用原有独立备份。完整离线备份可在停止服务后复制整个用户目录；不要将 Key、Cookie、配对令牌或私人数据公开上传。

## 内容质量边界

商品名称、品牌、采集价格、评分和评论数是历史页面资料；卖点、规格和功效文字是商家宣传，未独立验证。用户画像、创意、营销机会和竞品 AI 结论属于推断。没有真实评论正文，不声称已经分析消费者评论；没有观看或上传媒体，不声称已观察图片、视频或实际使用效果。

脚本检查开场、痛点 / 需求、解决方案、产品展示和行动引导，提示文字量与目标时长的明显冲突。文字估算不等于真实拍摄、口播或成片时长。结构验证和 Mock 示例不能证明真实模型事实、语言或商业效果达标；实际发布前请核查认证、参数、功效、市场规则及品牌资料。

## 数据兼容与限制

`templates.json` 与 `content-plans.json` 独立于商品和对比文件。已有商品 ID、分组标签、AI 历史、配对和启动器设置继续保留。每类最多 200 个自定义模板 / 内容方案，每个最多 50 个历史版本，备份及数据文件最多 25 MiB；达到上限时明确拒绝，不截断历史。

v0.8.0 可以在详情或对比中直接选择商品、模板和有来源的竞品结论；保存的商品分析明确作为推断引用。内容方案的来源状态会提示商品 / 模板 / 对比更新或删除，明确创建新方案才能使用最新资料。创作参考素材只保存所属商品快照的安全 URL，模型只收到数量；各生成版本保留当次选择。完整业务备份及 50 版本容量整理见[完整工作流指南](workflow-backup-guide.md)。

新版回退到旧程序前应保留完整备份。旧程序不识别模板和内容文件，也可能不识别新用量字段；不要让旧程序写回新版用户目录。使用升级前副本进行回退。
