# 商品库、批量操作与本地备份

适用于 ProductSpy 0.5.0。仅支持 Amazon；批量操作不会调用 AI。

## 分组与标签

打开「商品库」，通过「分组与标签」管理名称和颜色。一个商品可加入多个分组并拥有多个标签。选择商品后可批量加入、移出分组或添加、移除标签；「移动分组」会替换所选商品原有的分组关系，操作前需要确认。

删除分组或标签只删除定义及关联，不删除商品、媒体、AI 分析或历史。删除商品会删除其资料及全部分析历史，先备份再确认。

搜索标题、品牌或 ASIN，并结合来源、分组、标签和分析状态筛选。筛选与显示偏好保存在当前浏览器；分页限制单页的卡片数量，大量商品仍可选择全部筛选结果。批量操作最多处理 500 个商品。

## 导出

- CSV：商品基本资料，用于表格查看；危险公式前缀作为文字导出。用 CSV 不能恢复完整分析。
- JSON：完整商品资料，包含分析、历史和关联的分组、标签。
- Markdown：已保存的分析内容；没有分析的商品显示相应提示。
- 本地备份：全部商品、分析历史、分组及标签。备份不含 API Key、AI 设置、扩展配对凭据或用量账本。

导出前可以调整选择；备份包含用户商品和人工编辑，是私有资料，请保存到自己的安全目录。导出文件不会上传到云端，也不会下载媒体文件。

## 导入与恢复

选择 JSON 文件后先验证格式、结构、URL、大小以及重复记录，再显示预览。单个文件最多 25 MiB、2,000 个商品。支持旧版商品数组和 ProductSpy 的完整备份格式；CSV 不支持导入。

预览发现相同 Amazon ASIN 时，可以跳过，或明确保留本机已有资料。两种选择都不会覆盖现有 ID、分析、人工修改和历史。恢复采用合并方式，不清空当前商品库；导入前可取消。确认后服务器会再次校验文件及预览版本，如商品库已变化，需要重新预览。

提交过程中请等待结果。连接中断不意味着服务器没有保存；刷新商品库核对结果后再决定是否重新导入。重复 ASIN 的安全处理可以避免二次导入覆盖已有资料。

所有批量操作都显示成功与失败数量；部分商品不存在或在其他页面更新时，失败项会留下供检查。不要把部分成功提示理解为全部完成。

## 数据格式和升级

旧 `products.json` 是商品数组。0.5.0 读取时提供空分组、标签默认值，不改写原文件；首次成功写入后使用原子替换保存为：

```json
{
  "schemaVersion": 2,
  "products": [],
  "groups": [],
  "tags": []
}
```

商品新增可选 `groupIds`、`tagIds`。缺失时表示无分组、无标签；不会新增或重设商品 ID、ASIN、创建时间、分析和历史。重复采集商品继续保留分组和标签。

导出文件使用单独的交换格式：`format: "productspy-library"`、`schemaVersion: 1`、`exportedAt`、`products`、`groups`、`tags`。该版本号与本地存储版本号无关。

升级时停止旧工作台，将新版解压到新文件夹再启动；独立用户目录继续保留。不要把 0.5.0 写入后的文件交给 0.4.0 直接打开：旧版不识别新版分组格式。需要回退时使用升级前的备份，先保存新版数据。

商品库备份不能代替完整用户目录备份。要备份启动器设置和用量账本，停止工作台后备份用户目录；Windows DPAPI 的设置仍绑定当前 Windows 用户。详见 [Windows 指南](windows-guide.md)。
