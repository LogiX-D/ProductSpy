# 素材与竞品对比指南

适用于 ProductSpy 0.6.0。先启动本机工作台、安装并配对扩展，再保存 Amazon 商品。

## 选择素材来源与保存目录

在商品详情的「素材」标签中，图片与视频分别展示。图片来源下拉框只列出此商品实际采集的 URL，不拼接或猜测高清地址。显示的尺寸来自页面结构化数据；未知尺寸不代表高清。旧商品缺少提取时间时显示记录更新时间，主动重新采集可补充元数据。

Windows 用户点击「选择保存目录」，在系统窗口中选择实际文件夹。勾选图片后开始保存；视频仅在识别为允许域名上的公开 MP4 / WebM 时提供下载。结果逐项列出成功、重复、失败原因，可以取消并仅重试失败素材。下载会保留已经完成的文件，不自动覆盖同名文件。保存会话 30 分钟有效，过期或服务重启后重新选择目录。可以「打开保存目录」或「打开文件位置」。

文件名含商品名、ASIN、图片/视频类别、序号；目录保存额外包含内容 SHA-256 短码。来源 JSON 清单包含所属商品、页面地址、资源 URL、时间、哈希、大小、结果。签名 URL 可能失效，请把清单作为自己的资料保管。重复 URL 合并为素材；下载后按实际字节 SHA-256 复用相同文件，不把名字相似当作内容相同。

「另存全部图片 ZIP」及单项另存可使用浏览器文件选择窗口。浏览器没有该 API 时，必须先开启浏览器的“下载前询问每个文件的保存位置”并勾选确认；应用不能核实这个浏览器设置，不能保证第三方浏览器一定展示保存窗口。推荐 Windows 目录保存方式。ZIP 附来源清单，某项失败仍保留其他成功内容并报告失败数。

安全限制：图片 10 MiB、直接视频 64 MiB、ZIP 80 MiB、单次目录保存 300 MiB。仅从允许的 Amazon HTTPS 媒体 CDN 请求；拒绝重定向、认证内容、伪造文件签名。HLS 仅标识为流媒体并提供原始链接，不下载、不转换、不绕过保护。不是所有公开 Amazon 视频域名都在白名单内。Windows 原子发布依赖支持硬链接的文件系统；不支持时给出保存失败，使用浏览器另存到其他目录。系统目录窗口与文件管理器仍须在普通 Windows/Chrome 上人工确认。

## 保存并管理竞品方案

进入「竞品对比」，选择 2–5 个不同 ASIN 的已保存 Amazon 商品；也可在商品库多选后点击「加入竞品对比」，或从详情加入。输入名称并保存方案。表格可横向滚动，勾选「高亮差异」；窄屏也能使用键盘聚焦和横向浏览。

价格、评分、评论数和素材数量属于历史页面采集记录。不同币种不进行高低排序或汇率换算。未采集字段显示未知；规格和卖点是商家页面列出的资料，未经独立实测。评论数不等于已分析评论正文。

方案保存完整商品快照，独立于原商品库。原商品更新时显示提示，只有点击并确认「刷新商品快照」才更新方案；已删除商品的快照仍保留。增删对比成员不改原商品。删除方案须确认，只删除方案与其对比分析历史。CSV 和 Markdown 可导出表格，CSV 对公式字符进行转义。

## AI 对比与结果历史

保存方案后设置市场、语言、平台、风格、时长和自定义要求，与商品分析共用偏好。没有 Key 时明确标识 Mock；它验证工作流，不代表真实 AI 质量。真实请求每次弹出授权提示，发送商品文字和要求，不传媒体文件或媒体 URL。没有自动重试，费用、Token 和请求数沿用本机用量保护。

结果分为七个分区：核心差异、可核实卖点比较、目标用户差异、营销机会、差异化内容角度、短视频建议、待确认风险。证据按页面记录、商家宣称、AI 推断及未验证信息展示。结构验证不能保证模型不编造，使用前须人工核查。

可复制条目、分区与整篇、导出 Markdown，编辑每行一个条目并保存为新版本。重新生成与恢复都会新增历史，不覆盖原结果或人工编辑；每个方案上限 50 版本，满后停止生成，不自动删除。请求中断先「检查已保存结果」，同一编号不会重新收费。草稿在当前标签页暂存，关闭浏览器前应保存或导出。

## 备份、更新与回退

原商品库 JSON 备份继续包含商品、分组、标签和商品分析历史。「竞品对比」的「备份与恢复」另存完整方案及对比分析历史；两份需要分别保存。对比恢复先验证格式、大小、所有商品快照与历史，再显示冲突；重复方案保留本机资料，不默认覆盖。恢复不会清空原商品库。

精确备份请停止服务后复制完整 `%LOCALAPPDATA%\ProductSpy` 用户目录。对比文件为 `data/comparisons.json`，原商品仍在 `data/products.json`；目录下载的文件及清单在自己选择的文件夹中，需要另外备份。JSON 导出不含 Key、配对凭据、Cookie、启动器设置、用量账本或浏览器偏好。DPAPI 设置只适用于原 Windows 用户。

更新到 0.6.0 前停止旧服务并备份，把新版解压到新目录。读取 0.5.2 不重写旧库；新提取字段可选，不修改原 ID 或分析历史。旧版不识别新增商品字段，回退须使用升级前完整备份，不能让旧版写回新版库；独立对比文件不会被旧版本展示。
