## 已完成的工程质量验证

Provider 的 Mock/Stub 回归覆盖：参数传递、JSON/text/schema 输出模式、`max_tokens`/`max_completion_tokens`、不假定温度支持、拒答、输出截断、结构缺失、429 冷却、请求与响应大小、请求和正文读取超时、Token 信息缺失，以及不发送媒体 URL/文件。

返回的页面事实来自已采集字段，模型自己的事实列表不直接成为事实依据。提示词要求区分页面宣称、受众/需求推断与资料缺口，禁止编造规格、认证、效果或评论结论。未采集评论正文时，证据字段必须为 false；评分、评论数量不能代替评论分析。

请求文本有裁剪上限，裁剪会明确列为不确定性；旧商品数据不变。商业发布仍需人工审阅全部分析正文：结构校验、来源分类和提示词无法保证真实模型无幻觉。结构化输出的契约和拒答处理依据 [OpenAI Structured Outputs 官方文档](https://developers.openai.com/api/docs/guides/structured-outputs)，请求参数依据 [Chat Completions 官方文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。

## 当前商业质量结论

本机演示已具备完整结构、可追溯资料边界、参数化展示、版本保存和复制导出流程。Mock 的品类场景是确定性模板，不是模型推理；不同市场采用明确市场名称和待核查说明，没有证据支持的当地法规、文化偏好或购买动机不会作为事实承诺。

**不能把 504 项通过写成真实模型准确率、营销效果或转化提升。** 当前尚未验证：真实模型是否持续遵守事实边界、目标市场和语言的自然表达、具体营销创意质量、脚本朗读时长、自定义要求的语义执行，以及生产接口的延迟/费用。

## 后续真实模型人工评估步骤

以下为复现流程，未自动执行，也不自动调用收费 API。

1. 由用户指定服务商、确切模型、允许测试的 Key、最大请求次数、美元预算和截止时间。Key 只填写本机启动器或 `.env.local`，不放入报告、命令输出、截图或 Git。
2. 使用独立测试用户数据目录。准备至少上述六类商品的完整资料快照，并标记页面明确提供的参数、未提供信息、品牌与所选变体。测试不能用合成样本代替真实 Amazon 验收，也不能把采集页面文案当作实测证明。
3. 核对服务商单价，在工作台填写两项完整价格；优先设置服务商账户消费限制。ProductSpy 本机每日请求上限和输出 Token 上限都不是美元硬预算。
4. 在既定预算内选定小批量组合，逐次检查授权框中的市场、语言、时长、自定义要求和生成范围，点击「授权本次调用」。没有自动批量评测脚本。失联、超时或限流先查账单，不自动重发。
5. 导出 Markdown/TXT，记录模型、参数、版本编号、可用的 Token 用量和估算金额。缺少用量或单价时明确标为未知；以服务商账单核算是否还有预算。
6. 两位审阅者按下表独立评分，保留具体原文、问题和修改建议。事实核查回到商品资料，不用另一个模型输出作为唯一证据；语境和自然度由熟悉目标语言/市场的人审阅。
7. 出现编造规格、虚构认证/功效或冒称真实评论分析立即标记失败并停止该样本发布。达到预算、请求次数或截止时间就停止，剩余组合记为未测试。
8. 修订 Prompt/Provider 后用相同样本和参数在新的明确授权预算内复测，通过版本比较检视差异，不覆盖原有分析与人工修改。

| 人工维度       | 0–2 分准则                                                                                         |
| -------------- | -------------------------------------------------------------------------------------------------- |
| 事实准确性     | 0：出现无来源功能、规格、认证或效果；1：表述含混/有遗漏；2：每项关键事实可追溯且页面宣称与实测分开 |
| 推断和评论边界 | 0：把猜测/评论结论写成事实；1：部分假设标注不足；2：推断、资料缺口和未读评论明确可见               |
| 营销具体性     | 0：通用口号；1：提到品类但缺少具体画面；2：使用真实资料提出可拍摄角度与明确购买核查步骤            |
| 市场/语言匹配  | 0：语言不符或无依据的当地承诺；1：生硬翻译；2：母语表达自然且对市场差异保持事实依据                |
| 脚本可执行性   | 0：虚构演示或明显超时；1：需大幅修改；2：正常朗读和实际拍摄可覆盖五段、所选时长与平台方向          |
| 自定义要求     | 0：忽略或违反；1：部分满足；2：逐条满足且不突破事实/安全边界                                       |

可采用“关键事实错误为 0 个、六维合计至少 10/12 分、两位审阅者一致认可”作为后续小批量发布门槛；这是建议的人工验收门槛，**本轮尚未达到或测量该分数**。评分不代表市场转化实证，转化效果需要后续独立实验。
