# Phase 13：商品库管理与批量工作流

日期：2026-10-09。版本：0.5.0。基于 Phase 12 的 `7a3c919` 开发；保留 Next.js、MV3、安全配对、服务端 AI、历史版本和 Windows 便携启动器。本阶段没有其他电商平台、云端服务、付费账号、批量 AI 或 Chrome Web Store 提交。

## 实际功能

- 多分组、彩色标签：创建、重命名、改色、删除；一个商品可有多个分组和标签。删除定义只移除关联，不删除商品和分析。
- 商品库组合筛选、排序、36 件分页和跨页多选；一次最多操作 500 件。支持加 / 移除标签、加 / 移出分组、移动至单一分组、导出与删除。
- 删除、移动和移除关联有二次确认。确认时固定商品编号、版本、操作及目标；自动刷新不会让用户确认另一份新资料。逐项报告成功 / 失败，失败项保留。
- CSV 基本资料、完整 JSON、分析 Markdown；JSON 导入及完整商品库备份恢复。交换文件包含分析、完整历史及分组标签，排除 Key、配对凭据、Cookie、设置和用量账本。
- 导入最多 25 MiB / 2,000 商品，整文件结构验证；异常字段、恶意 URL、重复编号、悬空关联、重复历史版本拒绝导入。先预览冲突再确认，提交再校验预览版本；重复 ASIN 的两种选项都保留本机资料，恢复不会清空已有商品。
- 重新采集保留商品 ID、创建时间、分组标签。已有分析仍按原 Phase 12 规则归档；分组修改不会改写分析正文或历史。

## 数据结构与升级

旧 `products.json` 商品数组只读兼容，不在启动或读取时迁移、重写。首次成功写入改为 `{schemaVersion:2, products, groups, tags}`，商品新增可选 `groupIds` / `tagIds`；缺失值按空关联显示。分组和标签均含 UUID、名称、颜色、创建和更新时间。

所有商品与分类使用同一事务队列、同一个临时文件和原子替换；不会先保存商品再保存分类导致半份更新。写盘失败时整个请求失败，不提前报告成功。分类和批量修改也校验旧分析与完整历史。

交换文件单独使用 `{format:"productspy-library",schemaVersion:1,exportedAt,products,groups,tags}`，不是本地存储文件。详细操作与安全边界见 [商品库指南](library-guide.md)。新版写入后的文件不能直接交给 0.4.0 程序读取；回退需使用升级前备份。

## 修复的实际问题

1. 500 个长商品 ID 放进 GET 导出 URL 可触发 HTTP 431：实际本机 Node 重现后，选中导出改用 POST，未放宽请求头上限。
2. 确认期间五秒轮询可改变待删除版本：固定确认请求，E2E 在确认期间更新价格，结果为失败并保留新商品。
3. 已删除商品仍留在隐藏选择集中，重新采集会自动复选：仅在成功读取权威库后清理失效选择并提示；失败或离线缓存不清理。
4. BOM JSON 第一次通过验证、再次解析失败：二次解析同时移除 BOM，保持整文件校验。
5. 新商品库读取接口替代旧列表，原离线测试未实际断开：同时拦截新旧接口，保留本机缓存及原商品完整性断言；UI 清晰显示缓存状态并禁用写入。
6. 批量部分失败测试缺少成功项的期望版本：补齐测试请求的逐项版本，保留服务端缺版本即失败的规则。

## 安全性和限制

所有分类、批量、导入和导出接口仅限已认证工作台，保留 Host、Origin、会话、CSRF 和 CORS 检查；已配对扩展也不能访问这些管理接口。CSV 中公式及前导控制字符转为文本；Markdown 转义 HTML / 链接等内容。导入拒绝可执行协议、凭据、特殊端口、IP 和常见内网地址，商品 URL 必须是匹配 ASIN 的 Amazon 页面。

- 导入不访问媒体地址；URL 检查不是 DNS 重绑定或所有恶意公开站点的完整检测。原图片下载的允许域和 SSRF 防护保留。
- 恢复为非破坏性合并，不提供覆盖当前库或混合 AI 历史的选项；相同 ASIN 的导入修改不会覆盖本机。备份不含启动器配置、配对或用量记录。
- 批量最多 500 件；单文件最多 2,000 件 / 25 MiB。超过导入上限的完整备份会明确拒绝，需缩小选择分批导出。商品库最多 10,000 条，未对 10,000 条作性能保证。
- 商品和备份没有应用级加密；继续使用独立用户目录，DPAPI 只保护启动器设置。备份包含商品和自定义分析要求，属于用户私有资料。
- 本轮没有真实 Amazon 实页采集、真实模型质量或收费调用。浏览器为 Chrome for Testing 156.0.8078.4；常见正式 Chrome 安装位置均未发现程序。正式 Chrome、WinForms 手工鼠标操作、高 DPI、全新电脑和签名提示仍待人工验收。

## 复现

先退出自己的 3000 服务，在项目根目录依次运行；测试只停止自己确认拥有的服务，不结束其他监听进程：

```powershell
pnpm install --frozen-lockfile
pnpm typecheck
pnpm lint
pnpm format:check
pnpm test
pnpm build
pnpm test:e2e
node scripts/package-windows.mjs
pnpm test:portable
pnpm test:upgrade --from artifacts/ProductSpy-0.4.0-windows-x64 --to artifacts/ProductSpy-0.5.0-windows-x64
node scripts/validate-release.mjs
```

`pnpm test:library-performance` 可单独重跑合成商品性能及九张截图；结果写入 `.test-data/phase13-performance/<时间>/report.json`，图像写入 `artifacts/ProductSpy-0.5.0-library-experience/`。升级测试必须保留冻结的完整 0.4.0 便携包，不能用同版本改目录冒充升级。
