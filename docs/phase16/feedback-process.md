# Phase 16：3–5 位外部用户独立封闭测试流程

准备日期：2026-10-13（北京时间）。**这是待执行流程，尚未确认外部参与者、发送邀请或收到真实反馈。** 仓库既有 [Phase 14 反馈状态](../closed-test/feedback-summary.md)记录参加人数 0、反馈 0；本次检查未发现新增填写记录。计划 3–5 位用户不是实际人数，维护者本机自测也不计为外部用户。

## 准备与隐私

维护者先取得真实参加者同意，私下提供冻结 Windows 包、Extension ZIP、版本/提交/校验值和 [当前安装指南](../windows-guide.md)。草稿 Release 不是公开下载页，需要相应权限；可私下交付原包和哈希。不要把仓库源码 ZIP 当安装包。

尽量覆盖普通 Windows 10/11 x64、正式 Chrome 稳定版、无 Node/pnpm 开发环境和实际高 DPI。按实际设备记录覆盖，不因计划人数足够就判定设备覆盖通过。其他浏览器只作为额外兼容性观察；工作台网页与采集插件分开评价，自动操作工具不支持某浏览器不等于产品不支持该浏览器。

联系方式和同意记录只由维护者在受限位置保存。实际开始后才分配匿名编号；本文件不列虚构姓名或占位测试者行。用户可退出、跳过真实 AI 或拒绝提供私人商品。建议正常使用 3–7 天后追加日常价值反馈，实际周期和退出原因照实记录。

先导出并备份已有商品及完整用户目录；保留 AI 历史、设置和待同步商品。更新/恢复、批量删除、端口冲突和断线场景使用隔离测试资料，禁止为测试直接删除用户旧商品或保护文件，禁止关闭 Windows/浏览器安全机制。

## 独立使用任务

观察者首先让测试者按指南自己操作；需要帮助时记录步骤、原因、次数及帮助内容。失败/阻断不能被观察者代操作后的结果覆盖，修复后另记复测。

| 步骤          | 用户自行完成的任务                                                                | 记录与通过条件                                                           |
| ------------- | --------------------------------------------------------------------------------- | ------------------------------------------------------------------------ |
| 1 安装启动    | 下载/校验/全部解压，双击 ProductSpy.cmd，打开本机工作台                           | 正确版本、启动及工作台可见；记录安全提示原文和实际浏览器，不要求关闭防护 |
| 2 加载和配对  | 正式 Chrome 手动加载 Extension、固定图标，工作台生成一次性码并配对                | 实际渠道/版本、配对成功；脱敏截图不含码或令牌，过期重新生成也记录        |
| 3 首次采集    | 打开真实 Amazon 商品，阅读首次说明，核对可见标题/ASIN/价格/主图，保存并刷新工作台 | 商品保存且刷新保留；开始至成功的墙钟时间及暂停单列，受限网页记阻断       |
| 4 商品管理    | 自行创建/重命名分组和彩色标签，筛选，批量操作隔离样本                             | 分组/标签持久化、结果数量及失败提示明确；删除有二次确认，不动私人商品    |
| 5 Mock 与历史 | 生成 Mock、编辑摘要、局部再生开场、比较/恢复历史、导出                            | 明确 Mock；旧分析与人工修改保留，重启后历史仍在；不作为真实模型品质      |
| 6 备份恢复    | 导出完整 JSON，按冲突提示安全合并恢复，停止/重启                                  | ID/ASIN/分析/历史/分类保留；重复项未默认覆盖，记录备份和恢复实际范围     |
| 7 恢复与升级  | 隔离样本检查工作台断线、重连；保留旧目录，升级/回退前备份                         | 不丢已存商品；记录包哈希、设置/偏好及保护状态。未测某场景保持待验收      |
| 8 日常反馈    | 记录最常用功能、主要困难、是否愿意再用、最希望改进项                              | 仅用户真实回答；缺失为未回答，不替用户推断或填好评                       |

真实 AI 为可选独立任务，只有确切模型、授权 Key、请求上限和预算齐备才执行 [AI 验收流程](ai-validation-preparation.md)。Mock 与真实 AI 的人工编辑反馈分开统计；未授权不触发付费调用、不追问把 Key 发到聊天。

## 时间、状态与指标

[feedback.csv](feedback.csv) 初始只有表头、没有测试者或结果行。复制到受限本机目录后，每次实际安装/使用尝试一行，`participant_id` 仅真实开始后分配，`attempt_id` 唯一。首次与重试分别标记，同一人多次尝试不能当成更多用户。

状态使用 `success / failed / blocked / incomplete / not_attempted`；空白是尚未收集。时间为含时区 ISO 8601；耗时数值使用秒。保留首次失败、复测状态和实际帮助记录。填写文本按 CSV 引号规则转义；用表格软件打开前将自由文本字段设置为文本，避免把以 `= + - @` 开头的反馈当公式执行。

| 指标             | 计算方式                                                                           | 未收集/未完成的处理                                                     |
| ---------------- | ---------------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| 安装成功率       | 启动工作台、实际插件加载及配对均成功人数 / 实际尝试安装人数；另列首次和最终成功    | 失败/阻断/未完成都单列，下载前退出另列；分母 0 时未计算，不能写 0%/100% |
| 首次成功采集时间 | 首次双击到真实商品在工作台保存并刷新保留的墙钟秒数                                 | 未成功者无 TTFC；暂停秒数/原因单列，不静默扣除，不能用自动化时间代替    |
| 核心功能成功率   | 采集/保存、管理、Mock/历史、备份/恢复、重启分别为成功真实尝试数 / 该功能实际尝试数 | 失败/阻断/未完成/未尝试分开；不把重试平均成首次通过，独立 ASIN 另列     |
| 最常遇到问题     | 真实记录按故障原因及 P0–P3 分组，报告受影响人数和尝试次数                          | 工程故障、Amazon 阻断及用户操作困难分开；没有记录不编造排名             |
| AI 修改负担      | 实际审阅结果数、需修改数、比例、修改范围、有效编辑秒数和墙钟时间                   | Mock/真实授权模型分开；未检查或未测留空，未知不填零                     |
| 是否再次使用     | 愿意/不愿意/不确定各自人数 / 实际回答人数，附用户原因                              | 未回答单列；意愿不等于持续留存或付费                                    |
| 最希望改进功能   | 用户原始回答脱敏后分类，保留来源匿名编号                                           | 不根据项目路线图代填，也不据此立即增加新业务模块                        |

100/500 个合成商品性能样本不算真实用户商品；开发者自动化 Mock 不算外部反馈。3–5 人小样本只支持发现困难和缺陷，不用于推算全体用户成功率或市场付费潜力。

## Bug 处理与证据归档

用 [Bug 模板](../closed-test/bug-template.md)记录实际行为、预期、可复现步骤、版本/包哈希、OS/浏览器、影响范围和脱敏证据。P0 为丢数据/严重安全/无法启动；P1 为采集保存分析主流程失败；P2 为界面交互/结果异常；P3 为非关键体验。不能因一张缺上下文小图直接宣称根因或严重程度已证实。

P0/P1 优先停止风险路径、备份和复现修复；原始失败及修复后的同流程结果并列，关闭需修复提交和复测证据。不可复制用户浏览器 profile、Cookie、Token、配对信息、AI Key、完整私人商品库或未脱敏账单到仓库。

填写后的 CSV、身份映射与原始录屏放在维护者受限本机位置，公开仅发布经同意且审核脱敏的汇总。只有实际收到反馈后才新增反馈汇总；当前不生成虚构质量评分、安装率、TTFC 或用户评价。

## 公开测试决策

真实普通设备/正式 Chrome 的主流程、保存恢复、安全提示和实际 DPI 未完成，或仍有未结 P0/P1 时，继续封闭测试。维护者的本机陈述可以登记，但缺少逐项证据不得填成自动通过或外部反馈。真实 AI 未执行时可以继续 Mock 闭测，不能宣传真实模型质量达标。是否公开由本轮主报告结合实际证据决定；本流程不授权公开发布或提交 Chrome Web Store。
