## 已执行的工程验证

`apps/web/src/lib/ai/content-generation.test.ts` 使用明确标注的六类合成商品（电子、家居、美妆、鞋类、厨房、旅行用品），分别检查中文、英文、日文 Mock 输出的完整结构、五段脚本、至少五条开场、页面宣称和未知信息边界。Mock 内容是固定示例，不能据此得出真实模型语言、营销具体性或商业效果达标。

HTTP Stub 检查 OpenAI-compatible 真实调用协议：固定系统消息独立于模板、商品与用户要求；参数和 Prompt 放在不可信数据消息中；不提供工具，不发送 Key、媒体文件或媒体 URL。模型自报的事实和商家宣称由服务端重建，评论分析标记必须为 false。未知模型可能仍生成错误或夸大的内容，结构校验不是事实正确性证明。

生成请求在网络调用前完成参数、模板展开量、来源、版本容量、身份和明确授权检查，然后持久化请求编号与用量预留。重复编号不再联网；错误不自动重试；保存成功但用量结束写入失败时保留结果。自定义 45 秒参数按真实值记录，旧 15 / 30 / 60 秒分析记录仍可读取。用量账本不重复保留自定义 Prompt 正文，方案私有元数据保留生成参数以便复现。

脚本时长是文字启发式估算：检查口播文字量，提示与目标秒数的明显冲突；局部重新生成、人工编辑及恢复后重新计算。未录音、未拍摄或渲染，不代表实际说话速度、成片或拍摄时长。

执行方式：

```powershell
pnpm exec vitest run apps/web/src/lib/ai/content-generation.test.ts apps/web/src/lib/server/content-api.test.ts packages/shared/src/content.test.ts
```
