# Phase 19 安全与可靠性检查

版本 v0.8.0，2026-10-14。范围为实际源码审查、隔离数据根目录的回归与故障注入；不声称进行了外部渗透测试、真实断电测试或未执行的 Windows GUI 验收。完整自动化数量见最终验收报告。

| 检查项        | 实现与实际证据                                                                                                                                 | 边界                                                                               |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| 本机 API      | 保留 loopback 绑定、Host/Origin/Sec-Fetch 校验、HttpOnly / SameSite=Strict 会话；新备份、模板、内容、历史接口 web-only，拒绝匿名和伪造扩展来源 | 无法抵御已控制当前 OS 用户的恶意程序                                               |
| 扩展配对      | 单次 120 秒配对码、绑定实际扩展 Origin、服务器令牌哈希、撤销/重新配对与离线队列保留                                                            | 原 55×58 小窗口没有真实根因证据，仍待实际桌面复现                                  |
| 最小权限      | 原 MV3 activeTab/scripting/storage 与固定 localhost host，未添加广泛 Amazon 站点权限或远程代码                                                 | 正式 Chrome 稳定版手工安装仍待人工验收                                             |
| Key           | Windows CurrentUser DPAPI 设置、仅服务端读取；扩展、提示词、状态 API 与普通备份不含 Key                                                        | 商品业务 JSON 本身不提供应用级加密；停止后复制全用户目录会含私人配置，禁止公开分享 |
| AI 授权       | 保留逐次真实调用确认、持久化 requestId/指纹、限流/日限额/超时、无收费自动重试；此阶段真实付费调用 0 次                                         | 超时不能证明服务商未计费，先查已保存结果及账单                                     |
| Prompt 与引用 | 模板变量白名单、不递归执行；网页文字和模板放入不可信数据边界，固定系统规则，不提供执行工具。商品分析标记既有推断，竞品结论保留来源             | 结构验证不是内容真实性证明，真实模型质量未验收                                     |
| 媒体          | 保留 HTTPS Amazon CDN 白名单、私网/恶意域名拒绝、重定向拒绝、MIME/签名/大小限制、公开视频归属检查；HLS不伪装成直接文件下载                     | 页面视频归属与播放仍需人工核实，不绕过受保护资源                                   |
| 参考素材      | 只选原商品快照中来源匹配、安全域名的图片/MP4/WebM，去重及最多50；生成版本保留当次选择。模型只收到数量，ZIP只含文本                             | 不执行媒体视觉分析，不上传或复制媒体文件                                           |
| JSON/CSV/ZIP  | 既有严格 schema、URL、数量、文件大小和冲突校验；CSV公式转义、导出 ZIP 固定安全文件名/CRC校验；完整业务导入仅JSON                               | 未新增任意ZIP解压导入，避免路径遍历入口                                            |
| 完整恢复      | 五文件独占锁、staging/prepared/committed日志、原字节哈希、临时文件原子发布；预览CAS+二次确认；部分失败回滚、启动前恢复；异常日志原样保留并阻断 | 物理磁盘损坏/真实断电尚未执行                                                      |
| 暂存路径      | 固定文件名集合，拒绝 symlink/junction、未知文件/损坏日志，不访问外部目标；打包与Git排除 `.workspace-restore`                                   | 无法防止拥有当前用户权限的外部程序在检查后持续篡改文件                             |
| 请求账本恢复  | 保留已有 reservations/fingerprint/status；旧备份不可重置本日真实请求限制。独立测试真实mode仅预约，不调用Provider或配置Key                      | 普通备份含非认证单向请求指纹及业务用量，可分享前仍需检查文案                       |
| 历史清理      | 服务器签名归档凭证绑定实体/版本/完整哈希/更新时间/30分钟期限；当前/初始恢复节点/恢复来源保护；人工编辑不自动删除                               | 归档是人工恢复参考，现有同ID导入仍安全跳过                                         |

独立回归实际覆盖：四仓库完整历史 round-trip、重复ASIN不同ID原快照保留、预览后版本冲突、合并容量、部分发布失败原字节回滚、staging阶段崩溃恢复、prepared阶段读前回滚、committed清理恢复、异常/未知日志保留、共享锁不能发布、junction外部文件不变、私人设置/配对字节不变、并发恢复与账本写入全部ID保留、旧用量不能重置日限额。新接口的未授权访问与超大声明请求体均拒绝。

发行包另执行完整ZIP CRC、路径、敏感文件、疑似Key/Token、Manifest权限及内嵌扩展一致性检查；最终实际文件哈希见发行清单。原 v0.7.0 两个ZIP保持原字节。
