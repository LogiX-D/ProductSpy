2026-10-14（Asia/Shanghai）。远程 main 与本地初始提交均核对为 `08eefad297816b6b6b2cb236ba40ef7951960000` / v0.8.0。沿用既有架构，仅修复有证据的问题、补充候选版检查和交付材料。没有付费模型调用、外部用户邀请、商店提交或公开 Release。

## 实际修复和发布约束

| 编号     | 优先级   | 证据与处理                                                                                                                                                                                                       |
| -------- | -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| PS20-001 | P0       | 损坏停止请求 JSON 会跳过父进程存活检查，独立真实子进程在父 PID 已不存在时持续运行。分离控制文件解析与父进程检查；修复后 SIGTERM 退出，完整包继续检查异常启动器退出、重启与原资料保留。不是已发生的用户数据丢失。 |
| PS20-002 | P1       | 原启动前只创建目录，不能提前明确识别拒绝写入。增加独占创建、写入、落盘与清理探测，给出中文权限/空间提示；退出控制目录失效时只终止本次创建的服务对象，不提权、不清空数据。                                        |
| PS20-003 | P2       | 包内指南存在指向未分发报告/其他指南的坏链接。补齐完整业务备份与候选版指南，常用链接保留本地，历史报告转为 GitHub 来源，构建及回归检查所有本地帮助链接。                                                          |
| RC 版本  | 发布约束 | Chrome `version` 不接受 SemVer 预发布字符串。应用/ZIP 使用 `1.0.0-rc.1`，Manifest 数字版本 `1.0.0`，`version_name` 为候选版；新增严格映射、权限与内嵌扩展一致性校验。没有将正常 v0.8.0 描述为有此缺陷。          |
| 测试隔离 | 测试设施 | 新匿名 E2E 最初继承了 worker Cookie，实际返回 200。Trace 核实后显式清空 storageState，增加前后 Cookie 为空断言，保留三个 401 断言；定向生产 E2E 两项及最终全量回归另有日志。                                     |

便携测试的 ACL 清理辅助最初遇到 Windows 自动继承标志规范化，修正精确 DACL 恢复并在 C:/E: 实测，未删除或放宽原 SDDL 断言。升级测试最初在主动备份恢复后执行只读字节检查，导致属性顺序差异；把主动恢复移到严格检查之后，原断言保留，v0.8.0 定向 28 项通过，五条账本记录逐对象相等。两项均为测试设施问题，失败日志保留，没有误报用户数据丢失。

首次长任务中断时，单测/构建日志已生成，但全量检查没有完成报告，不能算整轮通过。完整重新执行，并将检查结果逐步落盘；Amazon 保留已执行六页（含书籍超时），只继续四个未执行页面。原失败 Trace 和日志留在忽略目录，不隐藏或删除失败记录。证据生成另外绑定本轮时间、最终包哈希、截图清单与 CRC，防止误用旧报告。

## 真实 Amazon 结果

[独立字段审计](phase20/amazon-results.json)：六类、四站（US/DE/UK/JP）、十个主 URL，**9 次采集、1 次书籍页导航 35 秒超时**；另一次正常可见 Crocs 变体切换成功，总计 7 个不同 ASIN。没有对失败页面猜测缺失资料，没有将超时认定为已证实反爬。

分母仅为 9 个成功主页面：ASIN、标题、品牌、主图、图库、已暴露高清来源、卖点、评分/评论数及主图网络检查各 9/9 一致；价格/货币 7/9，另外两页未知。视频页面归属结构 4/9，五页未提取；这不是播放/解码成功率。描述八页仍需完整内容核对，一页不可得。价格按页面实际 TWD 记录，不根据国家站强改币种。没有采集评论正文，没有进行消费者评论分析。

初始六页及后续四页为同一 RC 构建、独立匿名 profile 的两段实际执行，时间与原 HTML/截图哈希有记录；不是重复重试直到成功。原始页面/profile保留在 `.test-data`，公开报告只含字段裁决、公开来源及哈希。

## AI 工程和安全

新增三个正式路由与本机 HTTP Stub 连接，校验地址/模型/输出模式、逐次授权、结构、Token/估价、成功和失败幂等，以及 429 后人工内容/完整历史不变；六个本机请求，零个外部模型请求。估价数字是合成计价例子，不能作为实际账单。既有超时、限流、响应大小、HTTPS、重定向拒绝和 Key/上游错误脱敏测试继续保留。

13 文件 188 项独立安全回归通过，包含源/会话、Prompt不可信边界、媒体白名单、原子恢复/事务、归档与用量保护；新增用例包含在最终全量测试中。详见 [安全报告](phase20-security.md)和 [Windows 修复证据](phase20-windows.md)。没有发现新的生产 API 认证绕过，不因新测试上下文错误修改安全策略。

真实 Key、模型、次数及预算未授权，因此 **真实模型质量待验收**。Mock/Stub 不证明营销效果、事实准确度或真实语言质量。

## 自动化与产物

本机为非管理员 Windows 11 专业工作站版 10.0.26300 x64，Node 24.14.0 / pnpm 10.32.1；这不是所有普通 Windows 10/11 设备验收。

冻结安装、TypeScript、ESLint、Prettier、**71 文件 711 项 Vitest**、生产构建及构建后三次完整重复通过；**33 E2E** 通过，零失败、跳过、flaky。实际便携生命周期 13 项通过；v0.8.0 升级 28 项、v0.7.0 26 项、v0.6.0 22 项，v0.5.2 / v0.5.1 / v0.5.0 / v0.4.0 各 21 项通过。两包 ZIP 完整 CRC、路径、敏感文件、Manifest 权限及内嵌扩展共四项校验通过。均来自最终包生成后的本轮执行，原日志见机器报告。

主包为 `ProductSpy-1.0.0-rc.1-windows-x64.zip` 与 `ProductSpy-1.0.0-rc.1-extension.zip`，另有 `SHA256SUMS.txt`、版本发行清单、完整报告与实际界面截图 ZIP。Windows 包包含运行时、扩展和可离线阅读的七份指南及 FIRST-RUN，不含用户商品、配对、Cookie、Key、日志或 profile。包内 bundle-manifest 对每个文件提供 SHA；Release 附件再次与验收哈希核对。

截图见 [本轮截图来源与哈希](screenshots/phase20/provenance.json)，来自实际候选版便携服务、320/375/768/1280/1440px 页面及 400px Popup，无 DOM 替换/拦截响应。展示的商品沿用明确标注的历史真实公开采集，AI 为 Mock，不能当作本轮 Amazon 采集成功率。原配对 55×58 小空白窗口未获得复现根因，不能称为彻底修复。

## 人工待验收和结论

可见 Windows GUI 的启动动作被自动审批拒绝，工具仅返回 `blocked by policy`，未给具体原因，没有尝试绕过；[桌面证据状态](phase20-desktop-evidence.json)明确标为未通过。正式 Chrome 稳定版未在本机应用库存、常见安装位置与注册项发现；不另行安装或把 CFT 当作正式 Chrome。仍需正式工具栏 Popup、手工安装、原配对小窗口，以及普通 Windows 10/11 设备、SmartScreen、不同 DPI、原生目录完整操作、视频逐条播放、完整描述核对、实际断电/磁盘异常和经授权的真实模型质量验收。没有外部用户反馈数据可报告。

**功能候选版与工程验收可支持进入正式发布验收；全部真实环境与真实模型质量没有完成，不具备直接公开发布的充分证据。** GitHub Release 保持草稿，不提交 Chrome Web Store。安装、AI、完整工作流、故障排查、升级和已知限制统一见 [候选版指南](release-candidate-guide.md)；版本历史见 [CHANGELOG](../CHANGELOG.md)。
