日期：2026-10-14（Asia/Shanghai）。候选版 **1.0.0-rc.1**，冻结来源 `bcf049d45e65ea6da798b53aa6b57b20508927f9`。

完整 E2E 实际执行：扩展 Fixture 采集/离线暂存/重新连接保存 → 分组标签 → 素材选择 → 对比方案与 Mock 分析 → 商品 Mock 分析 → 模板 → 内容创作 → 人工编辑与候选版本 → 文本 ZIP 导出 → 完整业务备份 → **删除仅属于测试的资料** → 预览/拒绝过期修订 → 安全恢复。恢复后核对相同 ID、ASIN、来源、素材选择、人工结果、各模块历史、用量和幂等重放；保留本机较新商品。导出 ZIP 检查 CRC、固定路径、来源与人工口播，确认不自动附带媒体文件。
