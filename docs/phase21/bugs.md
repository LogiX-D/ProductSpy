## 最终收尾复核（2026-10-14）

没有收到新的维护者结果行、可定位的原生录像或真实用户反馈，`manual-results.csv` 的 53 项仍全部为 `pending`，未改写旧结果。没有新增可确认的生产 P0/P1；这不等于未经人工覆盖的场景不存在缺陷。完整判断见 [发布就绪报告](../release-readiness.md)。

- **小空白窗口**：工作台配对是同页 React 弹层；扩展使用 Manifest `action.default_popup`；工作台链接/启动器打开浏览器；启动器和 AI 设置使用 Windows Forms。源码没有创建 55×58 配对窗口的配置。历史裁剪图不足以确定属于哪一类，不能凭尺寸修复或关闭。C07 已收敛为一次连续录像及五组环境条件，不重复无关流程。
- **视频时序**：冻结 rc.1 在真实 CeraVe、OXO 页面各执行三次定次采集，CeraVe 视频数为 `2/2/2`、OXO 为 `1/1/1`，每次 ASIN 正确。采集前后 HTML 的冻结脚本回放与界面数量一致，未见后续数量增长；[证据](video-timing-final.json)含页面状态与时间。使用 CFT 无界面浏览器、在标签页打开真实扩展 Popup 页面，不能当作正式 Chrome 工具栏验收。前后采样间隔 874–1440ms，不是采集瞬间原子快照；未观测实际响应中的逐条 URL，未验证播放/下载。因此保留原始两项视频 `fail`，没有把历史原因改成“延迟加载已确认”或“解析器已修复”。
- **主动恢复**：现有「重新识别」每次读取当前商品页，不需新增功能或轮询。新增两项合成/Stub 回归覆盖同页延迟出现的当前 ASIN 视频、排除其他 ASIN、主动重采后保存最新资料及无自动轮询；它们证明工程行为，不证明真实页面的历史根因。测试框架同步 `act` 引起的状态更新警告已用标准异步 `act` 修正，未屏蔽日志或降低断言。
- **原生启动部分证据**：本次实际运行冻结包的非 Headless 启动器，隔离资料目录、Mock、`-NoBrowser`；Windows 进程标题为 ProductSpy、响应正常，本机 rc.1 服务在线。桌面工具没有返回可操作窗口对象，未点击 GUI 按钮或验证双击默认启动。通过自有 CLI 停止服务后，仅清理自有测试启动器，端口已释放；不能当作 GUI「停止并退出」通过。原始 [观察](native-final-observation.json)明确区分这些边界。本次启动已执行，不沿用旧阶段“GUI 启动被拒绝”的描述。

以上只修改验收工具、测试和文档，生产代码及冻结包未改，不建立 rc.2，不重复打包。真实 AI 无请求次数/预算授权，三个入口仍待真实质量验收，付费调用为 0。

## 提交和关闭要求

1. 记录最短复现、影响范围、受影响版本、来源哈希、错误原文与脱敏证据；不要上传完整用户目录或浏览器资料。
2. 可复现的问题直接定位修复，保留原人工内容、历史、配对与全部安全断言。测试失败先分析根因，不删除测试或降低要求。
3. 如修改候选版生产代码，生成新 RC 版本和独立哈希，保留 rc.1 原包可追溯；不能把不同二进制文件覆盖同版本。
4. 关闭缺陷至少需要同条件修复后证据、对应回归测试及全量工程结果。修复代码存在但原生条件未复测，状态应为“已修复，待同条件验收”。
5. 无法复现保留条件、尝试次数、时间和证据，记“待复现”或“本条件未复现”，不写“已解决”。人工反馈未收到时不虚构人数、成功率或评价。
