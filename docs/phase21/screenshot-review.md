主批次对 320/375/768/1280/1440px 记录文档宽度，未发生意外的整页横向溢出；对比表的容器内横向滚动保留。没有将 125/150/200% Windows 缩放换算成 viewport 宣称通过。

素材补充复测可在 Windows 项目根目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/phase21-media-check.ps1
```

它要求本机已有冻结 rc.1 解压包、保留的 `.test-data/phase17-amazon/acceptance/report.json` 和当前依赖，以及空闲 3000 端口。会在新 `.test-data/phase21-media` 中启动自己的无界面服务，只导入公开历史样本；不会访问默认用户库、操作原生目录选择、修改 Key 或调用 AI。已有服务时停止测试，不关闭它；最终仅停止本次所属的启动器。原始诊断输入、首次补充运行和日志保留在忽略的测试目录，不纳入候选安装包。

本轮没有发现足以据此修改生产 CSS/布局的已复现问题，因此保持候选运行代码和哈希不变。正式鼠标交互、SmartScreen、原生选择器、高 DPI、真实视频播放及原小窗仍按[人工清单](manual-acceptance.md)待验收。
