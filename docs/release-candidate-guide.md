# ProductSpy 1.0.0 安装与使用

这是基于 rc.2 制作的 1.0.0 正式版交付包，Release 仅为草稿，尚未公开。ProductSpy 只支持 Amazon，本机保存商品及营销资料，不需要注册账户、数据库、Node.js 或 pnpm。Mock 可以完整演示；真实 AI 由你配置服务并逐次授权。

## 普通 Windows 用户

1. 获取维护者提供的 `ProductSpy-1.0.0-windows-x64.zip` 和 SHA256SUMS；不要把 GitHub 源码 ZIP 当作便携包。
2. 全部解压到自己的普通可写目录，例如文档中的 ProductSpy 文件夹，不要在压缩窗口中运行。
3. 双击 `ProductSpy.cmd`，等待启动器显示工作台运行。自动打开地址为 `http://127.0.0.1:3000`；按钮可以再次打开工作台、插件目录、AI 设置和用户数据。
4. 保持启动窗口运行。结束时使用「停止并退出」或关闭启动窗口；关闭网页标签不会停止服务。

无需管理员权限。内置 Node.js 24.14.0 / PowerShell 5.1，面向 Windows 10/11 x64；具体通过的设备与未完成 GUI 项目以本次交付报告为准。重复启动不会新建第二个服务。端口冲突不会强行结束其他程序。

## Chrome 扩展与安全配对

点击启动器「打开插件文件夹」，然后在 Google Chrome 打开 `chrome://extensions`，开启开发者模式，点击「加载已解压的扩展程序」，选择包内 **extension** 文件夹。独立 Extension ZIP 同样先解压，再选择包含 manifest.json 的目录；不能双击 ZIP 安装。当前没有商店安装入口。

工作台「安装与配对」→「生成配对码」→在插件「工作台配对码」中粘贴→「连接工作台」。配对码 2 分钟内有效且只能使用一次；过期请重新生成。首次采集先阅读说明并点击「同意并开始采集」。固定插件到工具栏，打开 Amazon 商品详情页，检查商品资料后保存。

扩展 Manifest 的数字版本是 `1.0.0.3`，显示名为 `1.0.0`，高于 rc.2 的 `1.0.0.2`；工作台与发行文件均使用应用版本 `1.0.0`。重新加载通常保留本机队列与令牌；重新安装或目录变化可能改变扩展 ID，需要重新配对。卸载扩展会删除未同步资料，先同步再卸载。

## 从商品到营销成果

| 操作       | 入口与结果                                                                                    |
| ---------- | --------------------------------------------------------------------------------------------- |
| 采集、更新 | 插件检查 ASIN、价格、图片、卖点，保存到工作台；同 Amazon ASIN 去重，保留 ID 和历史            |
| 搜索与整理 | 商品库搜索、排序、分组、标签、分析状态组合筛选；批量删除需确认                                |
| 素材       | 商品详情「素材」或素材管理，区分图片/视频，选实际高清来源，批量下载到明确选择的位置           |
| 竞品       | 从商品库选择 2–5 件，保存对比方案；采集价格有时间，不同货币不排序为价格高低                   |
| 商品分析   | 详情「AI 分析」，设置市场、语言、平台、风格、目标与时长，生成后检查事实与推断                 |
| 模板       | AI 模板创建、复制、变量预览、收藏、版本恢复和导入导出；内置模板不覆盖自定义模板               |
| 内容创作   | 从商品详情或模板进入，选商品和模板，可引用有来源的既有分析、竞品结论和参考素材                |
| 人工与历史 | 编辑后明确保存；重新生成保存候选版本，不覆盖已有人工结果。来源更新/删除会提醒，旧快照继续保留 |
| 导出       | 商品 CSV/JSON，分析 Markdown/TXT，内容单项/整套 Markdown/TXT/JSON/文本 ZIP，对比 CSV/Markdown |
| 完整备份   | 「设置与备份」导出五类业务资料，恢复先预览引用、冲突与容量，再二次确认                        |

素材仅从允许的 Amazon HTTPS CDN 下载，显示进度、失败及取消；失败可明确重试。MP4/WebM 只有可直接访问且校验通过才下载。HLS、失效或受保护视频保留状态与原始链接，不绕过 DRM、登录或验证码。素材文件需自行另外备份，文本内容包不复制媒体。

## AI 配置与费用

默认 Mock 完全在本机运行，页面明确标注演示，不证明真实模型质量。启动器「AI 设置」填写自己的 HTTPS API 地址、模型、Key 和兼容参数，保存后停止并重启；配置 Key 或打开页面不会发起收费请求。

真实服务需兼容 Chat Completions；json_object、json_schema、text 与 Token 参数根据提供商选定，不自动试探或重复请求。每次点击真实生成都需单独确认授权，Key 由服务端读取，Windows 设置以当前用户 DPAPI 保护，不进入插件或普通业务备份。超时/失败可能已计费，先检查保存结果、用量与服务商账单，再决定是否另发请求；没有无限自动重试。

没有采集评论正文时，评分/评论数不代表评论分析。商家宣传、页面资料、已有 AI 推断与未知信息有不同边界，AI 输出需人工核实。Token 缺失与费用未知不能视为免费，费用估算以自填单价和实际返回 Token 为依据。完整说明见 [AI 指南](ai-provider-guide.md)。

## 备份、更新和回退

用户目录是 `%LOCALAPPDATA%\ProductSpy`，和程序解压目录分开。普通完整业务备份覆盖商品/分组标签、竞品、用户模板、创作方案、各自保留历史和用量；可选浏览器偏好。它**不包含 Key、Cookie、配对凭据、Windows 加密设置、草稿或下载媒体**。

恢复时先预览，再选择跳过或保留已有资料并确认；同 ASIN 冲突不覆盖已有人工分析。资料在预览后改变会拒绝旧预览，重新预览即可。异常恢复日志会保留并阻断，不能删日志强行继续。每种实体历史最多 50 份；接近上限可先归档，再确认清理指定旧版本，保护当前及恢复节点。历史归档是恢复参考，不能直接覆盖现有同 ID 实体。

更新前先导出业务备份，再停止程序，复制整个用户目录作为**私人回退副本**，另行保管下载媒体。该副本含私人设置和配对，不能上传 GitHub。将新版解压到另一目录启动，用户数据继续沿用；旧程序可能不理解新增字段，回退应恢复升级前副本，不能用旧程序直接写新版目录。流程见 [工作流与备份指南](workflow-backup-guide.md)。

## 故障排查与验收边界

| 情况                | 操作                                                                                                                    |
| ------------------- | ----------------------------------------------------------------------------------------------------------------------- |
| 3000 端口冲突       | 退出自己已运行的旧工作台或其他占用程序，再启动；不强制终止陌生进程                                                      |
| 用户目录不可写      | 检查目录权限、磁盘空间及企业策略，使用当前用户可写目录，不需要默认提权                                                  |
| 插件离线            | 启动工作台，必要时重新配对，点击「重试同步」；暂存商品保留                                                              |
| Amazon 采集失败     | 确認商品详情页并等待加载，点击重新识别；访问限制按 Amazon 正常流程处理                                                  |
| Chrome 工具栏小窗口 | 维护者已在原故障电脑的正式 Chrome 确认 rc.2 修复；如仍出现请记录版本、缩放和截图，见 [Hotfix 报告](rc2-popup-hotfix.md) |
| AI 失败             | 先核对模式、地址、模型、兼容参数与用量；已有人工结果保留，不自动收费重试                                                |
| 资料不见或损坏      | 停止服务，保留用户目录原文件及日志，核对当前 Windows 用户与数据目录；不要清空后再试                                     |
| Windows 安全提示    | 当前未商业签名；核对维护者来源和 SHA256，不代表已获系统或商店审核认证                                                   |

工作台网页可在其他浏览器使用，但正式扩展验收目标是 Google Chrome，其他浏览器兼容性不保证。网页响应式/CFT 自动化不替代正式 Chrome 工具栏、高 DPI、SmartScreen 和原生文件窗口的人工验收。正式版工程结果见 [交付报告](stable-release-validation.md)，其余人工待验收项保持原记录；真实付费 AI 质量未获授权时保持待验收。采集价格是页面历史快照，不是实时监控。
