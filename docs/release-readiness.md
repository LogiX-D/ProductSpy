## 公开发布前的必要核对

**下一批优先 B03 → B04 → B08**，不重复已确认的正常恢复和 Windows 生命周期：

1. **B03 取消预览**：在新隔离目标库记录基线，预览确实有待新增的合成备份，再取消；刷新及重新导出核对业务内容未变。它风险较低，先校准人工取消路径。
2. **B04 冲突保护**：保住较新人工编辑是本批数据安全价值最高的检查。在同一合成环境先导出旧备份，再保存较新人工标记，预览旧备份、选择安全保留并二次确认，核对新内容/历史及实际成功/跳过/失败数。
3. **B08 重复操作与重启**：复用前述资料，检查重复预览/恢复不新增重复、不覆盖现有资料，再重启核对完整结果及配对保持。W06 普通重启通过不能替代恢复冲突后的此项核对。

首项具体步骤见 [B03 操作单](v1.0.0-windows-lifecycle-manual-results.md#首项-b03取消预览且业务资料不变)。只用新 DataRoot/RuntimeRoot 和专用 Chrome，不清空原库、不改原备份/业务 JSON、不删恢复日志；自定义目录继续同一隔离入口，不误开默认生产库，不调用付费 AI。

**随后 C06 扩展重载**：先同步已有队列，按原标准在管理页重新加载扩展，核对必要状态、队列及已有商品；需要重配时如实记录，不卸载。C08/W06 不自动覆盖扩展重新加载上下文的保持行为。

**支持环境兼容性**：按首发承诺环境补 W11 权限拒绝和 W13–W15 的 125%/150%/200% 实际 Windows 缩放。W12 SmartScreen/Defender/策略提示可随正常操作同步记录；未出现只记本机未出现，不绕过安全保护。权限只用独立预备样本，不改生产 ACL；没有相应设备条件继续 pending，不用浏览器缩放替代。其余页面/媒体等风险按现有记录审视，不制造新 Bug。
