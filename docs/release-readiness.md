## 本次实际完成的定位

### 55×58 小空白窗口

只见关闭按钮的历史裁剪图无法确定窗口所有者，本次没有相同条件的复现录像。源码路径已区分：

| 类型                  | 当前实现                                          | 本次能确认什么                                                      |
| --------------------- | ------------------------------------------------- | ------------------------------------------------------------------- |
| 工作台网页弹层        | `workspace-shell.tsx` 同页 React 安装/配对弹层    | 没有新建浏览器窗口的调用；不能由此推断历史图片属于该弹层。          |
| Chrome 扩展 Popup     | Manifest V3 的 `action.default_popup`，400px 布局 | CFT 页面检查不等于正式 Chrome 工具栏窗口及 DPI 验收。               |
| 浏览器标签页/独立窗口 | 启动器打开默认浏览器 URL；扩展使用新标签页/链接   | 无代码指定 55×58 浏览器独立配对窗口；浏览器原生行为需完整边界证据。 |
| Windows 原生窗口      | 启动器、AI 设置和目录选择                         | 不能把原生窗口与网页/扩展 Popup 混称同一问题。                      |

保留“待复现”，不声称根因已修复。[C07 操作](phase21/manual-acceptance.md)已收敛为一次连续录像及五组条件；没有必要重复已通过且未受改动影响的业务链。

### CeraVe / OXO 视频

本次使用冻结扩展和 **Chrome for Testing 156.0.8078.4，headless，1365×900**，每个真实公开 Amazon 页面仅正常导航一次；现有扩展 Popup 页面在标签页打开，通过同意/「重新识别」按钮各采集三次。只做定次等待（初次 1800ms，此后 3000ms、5000ms），没有无限轮询、保护绕过、配对、商品写入或付费调用。

采集前后记录时间、readyState、当前 ASIN、结构化数据哈希和回放结果，见 [完整定次证据](phase21/video-timing-final.json)及[可重复脚本](../scripts/phase21-video-timing.mjs)。回放只执行 SHA 校验过的 ProductSpy 自有冻结脚本，从不执行保留 HTML 内的 Amazon JavaScript。

**证据限制：**前后采样间隔为 874–1440ms，不是采集瞬间的原子快照；实际界面可观测到 ASIN 和数量，逐条媒体 URL 哈希来自离线前后回放，没有拦截真实响应验证 URL 集合。没有额外请求视频检查播放/下载。页面自动本地化为中文/TWD，本轮只核验视频时序和 ASIN，不据此作价格或国家站准确率结论。[原始 Amazon 结果](phase21/amazon-results.json)中两项视频 fail 保留，本次不追溯覆盖。

新增合成/Stub 回归证明：同一页面延迟补充当前 ASIN 数据后，现有「重新识别」能更新视频；其他 ASIN 被排除；保存使用更新后的资料；无主动操作时不会自动采集轮询。它们不是实际延迟加载的根因证据。

Popup 测试中同步 `act` 的异步更新警告已修正，58 项定向运行无该警告。完整单测中另有 6 条既有 `BridgePairing` 测试 `act` 警告，全部保留在日志；不是失败或原生配对小窗口的根因证据，未借此改动生产代码。
