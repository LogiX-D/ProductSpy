## 2026-10-19 获授权测试部署

用户已指定 CloudCone Ubuntu 24.04 amd64 测试主机，允许 ProductSpy 专属容器、数据库与 HTTPS；未授权生产服务、正式域名、付费资源或公开发布。独立 SSH 密钥保存在本机仓库外；公钥安装后实际 SSH 登录成功。访问资料和主机证据仅保存在忽略目录。

主机约 1GB RAM、1GB swap，初检 24GB 可用磁盘，443 已有代理。因此保留该服务，使用精确 HTTPS IPv4:8443，80 留给 ACME HTTP-01。应用与 Worker 使用池 3 / 并发 1、真实受限 PostgreSQL、Mock AI，支付关闭；实际运行、重启与恢复已验证，负载峰值和长期稳定性仍需测量。

本轮执行顺序：通过全部 Linux CI 后导出加密镜像包 → 校验来源与镜像身份 → 部署独立 Compose 项目和数据库 → 签发并验证受信任 IP TLS 与自动续期 → 公网注册、隔离、采集同步、Mock 任务、重启持久化和备份恢复 → 真实 MV3/真实 Amazon 及跨物理设备分别验收。仓库为 public，CI 部署包必须流式加密给仓库外私钥持有者，不能把 Actions artifact 称为私有。

测试主机已实际启动 PostgreSQL/Web/Worker，公网可信 TLS 健康 200，17 项网络 API 链路通过；Docker 29 内容摘要兼容检查已补齐。随后已分别执行 Linux CI 的实际 MV3/fixture 与实际 Amazon、额度、重启及备份恢复验证，结果见下段。真实 AI、支付沙盒及物理终端浏览器体验仍未验收。

本轮云端 API 17 项、云端 MV3 fixture 10 项、Free/合成 Pro/恢复 Free、三服务重启后实际 HTTPS 持久化、快照一致逻辑恢复及恢复库路由、age 加密异地副本与每日备份均已实测。真实 Amazon CI 在 HTTP 200 后未取得成功采集证据。用户明确将人工真实链路、物理终端及 AI/支付测试配置留待稍后；保持 Mock、关闭支付，阶段 10 未完成。完整事实见 2026-10-19 验证记录。
