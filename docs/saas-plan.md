2026-10-18 用户重新确认持续迁移指令：自主衔接审计、实现、修复和测试，在独立开发分支提交，不需要阶段确认。接续已有 `codex/saas-migration` 和 Draft PR #1，避免从零重写；不购买云服务、不公开插件、不变更生产、不合并主分支。正式域名、付费资源、生产凭据及公开发布仍需单独授权。

本轮复审优先完成：限制扩展成功同步副本的存储增长；任务轮询遇到限流后安全恢复而不重发 AI；生产数据库角色启动校验与独立事务迁移；当前机器静态、全量、真实 PostgreSQL 和浏览器验证。运行结果补入 `saas-validation.md`，不能把已有历史成功替代本轮运行。

邮件验证/找回、生产隐私联系人/保留期限、生产监控/备份演练是正式运营前继续项。持久队列及独立 worker 已有真实 PostgreSQL 历史证据；云端运维、真 AI、支付沙盒和跨物理设备仍需独立验收。
