# SaaS 迁移开发计划

目标与约束见 [requirements](saas-requirements.md)，现有实现审计见 [audit](saas-audit.md)。此计划跟随代码证据更新，不覆盖未验证项目。

| 阶段               | 当前状态             | 交付/下一步                                                                 |
| ------------------ | -------------------- | --------------------------------------------------------------------------- |
| 1 审计             | 完成代码审计         | 32 旧路由、全部前端、MV3、仓储、Windows 和部署链；基线回归                  |
| 2 技术决策         | 已实施               | 保留 Next/React/TS，PostgreSQL + JSONB 渐进迁移                             |
| 3 SaaS 基础        | 已实现，验收中       | Web/REST、容器、环境、公开健康、CI                                          |
| 4 账户隔离         | 已实现，持续核验     | 密码/持久会话/撤销/用户 scope/RLS；补账号找回及邮件核验                     |
| 5 扩展云通信       | 已实现，E2E 中       | 授权码、账户队列、幂等、alarm、网络恢复；生产 origin 待确定                 |
| 6 业务迁移         | 已实现，E2E 中       | 原商品/AI/内容/模板/竞品/版本/搜索/下载复用                                 |
| 7 套餐与支付       | 已实现合同与本机测试 | 服务器容量/AI 限制、Stripe Checkout/Portal/Webhook；沙盒与真实交易待验证    |
| 8 数据与恢复       | 测试数据验证中       | 原子业务备份、legacy 预览导入 CLI、PG dump/恢复策略；真实数据需指定归属账户 |
| 9 全链验证部署准备 | 进行中               | 实际 PostgreSQL、构建、MV3、浏览器；外部云/真 AI/物理设备仍未验收           |
| 10 最终验收        | 未完成               | 逐条核对真实链路，报告实际证据、提交和外部限制，不虚报完成                  |

当前执行允许自动修复和开发分支提交。部署与付费边界保持用户原始授权范围。邮件验证/找回、生产隐私联系人/保留期限、生产监控/备份演练是正式运营前继续项。不能将当前同步任务记录缩减为完整后台队列目标。
