# SaaS 产品要求与验收契约

2026-10-17 生效。正式架构为 Chrome MV3 Extension + 在线 SaaS 工作台 + 云端后端；优先于历史 Windows 工作台计划。普通正式用户只需 Chrome 与网络，不安装本地 Node、数据库或服务。

保留 Amazon 采集、商品库/详情、搜索筛选与管理、AI 分析/版本、内容计划/模板/历史、竞品与浏览器下载。增加真实账户、持久会话、多用户隔离、扩展账户授权与自动重试、服务端套餐/额度、订阅/Webhook、持久任务与可见失败、数据库备份/恢复、日志、限流、部署准备。

数据库优先 PostgreSQL；每用户商品/分析/内容/任务/使用/权益/审计必须严格隔离。服务器拥有用户身份和套餐，前端不可自报 owner 或 plan。AI/支付密钥只存在服务端，扩展所有可执行逻辑均随包交付，权限限定采集与指定 SaaS origin。

2026-10-23 用户要求接入主流 AI 服务商，采用管理员统一配置、用户选择渠道与模型。管理员以服务器 UUID 白名单授权；渠道密钥加密存储，只写入不回显，普通用户只能读取已启用的渠道和模型。支持 OpenAI、Anthropic、Gemini、DeepSeek、阿里云百炼、火山方舟、Moonshot、智谱、百度千帆、腾讯混元、MiniMax、硅基流动、OpenRouter 及自定义兼容渠道。渠道配置保存不调用 AI；任务在额度预留前锁定渠道、模型与配置摘要，执行时配置变化应失败，不自动改道或重发付费请求。全局 Mock 与支付关闭的既有测试限制继续有效。配置与验收边界见 [AI 渠道配置](ai-channels.md)。

2026-10-21 用户要求取消配对码：安装后自动连接当前浏览器的 ProductSpy 网页账号，未登录只需网页登录，不呈现扩展 ID/授权码输入。自动连接严格限定可信扩展来源和有效网页会话，凭证仍只存 trusted storage.session；账号变更、退出、Cookie 丢失和网络异常不能导致旧账号队列上传给新账号。旧手工 API 可兼容历史包，但不作为当前 SaaS 使用步骤。

初始套餐策略（可由后续产品决策修改）：Free 50 商品/月 10 次 AI；Pro 5,000 商品/月 500 次 AI。商品数为当前库容量，AI 按 UTC 月计数，所有模式均计，失败/中断也计，已完成 requestId 重放不重复消费。降级不删除已有数据，可清理或原样更新，不能继续增加超限数量。

验收必须覆盖：注册登录 → 加载/登录真实 MV3 → Amazon 实页采集 → HTTPS 云 API → SaaS 库展示 → 真实 AI → 保存 → 另一物理设备登录查看；多用户隔离、套餐、并发额度、离线恢复、服务重启持久化、构建自动化和部署可行性。fixture、本机 HTTP、Mock AI、同机隔离浏览器、离线签名测试均只证明各自范围；真实 Amazon、正式 Chrome、真实云、真实 AI、跨物理设备、Stripe 沙盒、真实交易单独记录。

保持 `b83027a` 及历史源码/数据/草稿包为回退基线。在独立分支实施；禁止删除生产数据、购买资源、公开插件、修改生产或合并主分支。域名、付费云、真实支付、公开发布需要单独授权。阶段自动衔接，遇到外部限制必须清楚说明。
