# ProductSpy SaaS 商店中文说明草案

状态：待正式环境、隐私信息与实际截图验收；未提交商店。

简短说明：采集 Amazon 商品资料，安全同步至 ProductSpy 在线 SaaS 工作台。

ProductSpy 帮助你把当前 Amazon 商品的公开资料保存到自己的在线商品库。在商品页点击扩展、阅读采集说明并同意后，可采集标题、ASIN、商品链接、价格、品牌、卖点、评分数量和页面提供的图片/视频链接。某些页面可能没有价格或视频，扩展会如实保留缺失状态。

在 ProductSpy 网站注册或登录，再用一次性授权码连接扩展。保存后资料通过 HTTPS 同步至该账号；断网时按账号保留待同步队列，网络恢复后有限重试。在线工作台提供商品搜索、分析历史、内容创作、任务与用量管理。普通使用不需要安装 Windows 本地工作台或本地服务。

AI 在工作台内由用户确认后执行；真实模式可能消耗套餐额度并向配置的模型提供商发送必要商品文字。Mock 会明确标记。Free / Pro 的实际额度及账单状态以工作台为准，付款启用后通过 Stripe 托管页面处理。

扩展只在用户触发时采集当前支持的商品页，不采集 Amazon Cookie、登录密码、配送地址或支付卡资料，不出售采集数据或用于广告定向。未同步资料保存在本机扩展存储中，卸载可能使其丢失；已同步资料保存在账号服务端。完整用途、共享、保留及删除规则须以正式发布前补齐的隐私政策为准。

发布前填写已获授权的官网、隐私政策和支持 URL，并以实际 SaaS 截图替换占位材料。不能沿用旧版“本地保存、无需账号、需启动 Windows 工作台”的文案，不能宣称尚未完成的云端、真实 AI 或跨设备验收。
