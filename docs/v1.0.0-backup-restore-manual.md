## 1. 关闭旧工作台，准备新目录

在自己的 ProductSpy 启动窗口点击「停止并退出」，确认窗口已关闭。启动器有全局单实例锁，服务固定使用 3000 端口；仅关闭浏览器不够。遇到占用提示，先确认并正常退出自己启动的程序，**不要结束陌生进程、删除生产数据或恢复日志**。

打开 Windows PowerShell 5.1，执行下面的准备命令。提示时输入解压后包含 `ProductSpy.cmd` 的文件夹，以及上述合成备份的实际路径。

```powershell
$PackageRoot = [IO.Path]::GetFullPath((Read-Host '输入冻结 v1.0.0 解压目录'))
$BackupInput = [IO.Path]::GetFullPath((Read-Host '输入本次合成 backup.json 完整路径'))
$Launcher = Join-Path $PackageRoot 'launcher\ProductSpy.ps1'
$PS51 = Join-Path $env:SystemRoot 'System32\WindowsPowerShell\v1.0\powershell.exe'
if (-not (Test-Path -LiteralPath $Launcher -PathType Leaf)) { throw '启动器不存在，停止验收。' }
if (-not (Test-Path -LiteralPath $BackupInput -PathType Leaf)) { throw '合成备份不存在，停止验收。' }
Get-FileHash -Algorithm SHA256 -LiteralPath $BackupInput
$TestRoot = Join-Path $env:LOCALAPPDATA ('ProductSpy-Manual-Backup\' + [Guid]::NewGuid().ToString('N'))
$SourceRoot = Join-Path $TestRoot 'source'
$TargetRoot = Join-Path $TestRoot 'target'
$SourceRuntime = Join-Path $TestRoot 'runtime-source'
$TargetRuntime = Join-Path $TestRoot 'runtime-target'
if (Test-Path -LiteralPath $TestRoot) { throw '测试目录已存在，停止；不要覆盖或删除。' }
$ProductionRoot = [IO.Path]::GetFullPath((Join-Path $env:LOCALAPPDATA 'ProductSpy'))
if ($TestRoot.StartsWith($ProductionRoot + '\', [StringComparison]::OrdinalIgnoreCase)) { throw '不能使用生产资料目录。' }
Write-Host "合成输入：$BackupInput"
Write-Host "源资料：$SourceRoot"
Write-Host "恢复目标：$TargetRoot"
Write-Host "生产目录（不得操作）：$ProductionRoot"
New-Item -ItemType Directory -Path $TestRoot | Out-Null
```

保留此 PowerShell 窗口供后续命令使用。先核对打印的合成备份哈希，并确认源、目标路径均不在 `%LOCALAPPDATA%\ProductSpy` 内。测试中不要双击无参数的 `ProductSpy.cmd`，它会使用默认生产资料目录。

## 2. 启动合成源库，用专用 Chrome 打开

```powershell
Start-Process -FilePath $PS51 -WindowStyle Hidden -ArgumentList @('-NoProfile', '-STA', '-File', ('"{0}"' -f $Launcher), '-NoBrowser', '-DataRoot', ('"{0}"' -f $SourceRoot), '-RuntimeRoot', ('"{0}"' -f $SourceRuntime))

if (-not (Test-Path -LiteralPath $Chrome)) { $Chrome = Join-Path ${env:ProgramFiles(x86)} 'Google\Chrome\Application\chrome.exe' }
```

这里隐藏的只是 PowerShell 控制台；应看到正常的 Windows 启动器窗口。核对其「用户数据」显示 `$SourceRoot`，工作台版本为 **1.0.0**，初始商品库为空。使用新 Chrome profile，不登录或同步账号，不导入私人浏览器资料；这样不会改变日常 Chrome 的同源偏好和草稿。

新资料目录没有 AI Key。只使用标明「本机演示 / Mock」的结果，预期外部 AI 请求和费用均为 **0**；不要配置 Key 或授权真实生成。若遇 SmartScreen、权限拒绝或组织脚本策略阻止，保留提示并记录阻塞，联系维护者处理，**不要关闭安全保护或绕过限制**。

## 3. 从合成源库导出一份备份

1. 进入「设置与备份」，选择 `$BackupInput`，查看恢复预览。确认是专项报告中的合成样本，数量与报告一致；不是自己的生产备份。
2. 选择保留本机资料的安全策略，完成二次确认，将合成输入载入空源库。若预览异常，取消并记录，不能跳过校验。
3. 检查商品、分组、标签、素材来源、竞品、商品分析、模板及内容历史均可查看；记下用于核对的商品 ID/ASIN、方案 ID 和人工编辑文字。
4. 点击「导出完整业务备份」，另存为测试目录下的 `manual-source-backup.json`。不要覆盖合成输入。记录文件实际位置和预览数量。

普通业务备份包括素材 URL 与来源元数据、保存的快照及历史；**不包括实际媒体文件、下载任务、API Key、配对凭据、Cookie、Windows 私人设置或未保存草稿**。本指南不配对扩展，也不测试视频在线可用性。浏览器偏好是可选范围；如勾选附带，需单独记录，并在恢复时明确勾选才应用。

## 4. 恢复到全新的目标库

1. 在源启动器点击「停止并退出」，关闭源专用 Chrome 的全部窗口。不要删除源目录。
2. 在保留的 PowerShell 窗口执行：

```powershell
if (Test-Path -LiteralPath $TargetRoot) { throw '目标目录已存在，停止；不要覆盖。' }
Start-Process -FilePath $PS51 -WindowStyle Hidden -ArgumentList @('-NoProfile', '-STA', '-File', ('"{0}"' -f $Launcher), '-NoBrowser', '-DataRoot', ('"{0}"' -f $TargetRoot), '-RuntimeRoot', ('"{0}"' -f $TargetRuntime))

```

3. 确认启动器资料路径为 `$TargetRoot`，目标库为空；路径不符立即停止，不能导入。
4. 在「设置与备份」选择刚导出的 `manual-source-backup.json`，核对数量、引用与冲突提示。空目标应没有业务重复冲突。
5. 选择保留已有资料，先查看预览，再二次确认恢复。记录成功/跳过数量与错误提示，不反复点击提交。
