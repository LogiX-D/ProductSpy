## 执行安全边界

- 不要求关闭Defender/SmartScreen、绕过组织策略、提权或改生产ACL。出现安全阻断记录原文并停止该项；没有提示只能写该机器未出现。
- Windows125/150/200%由设备所有者使用正常设置准备；浏览器缩放、deviceScaleFactor和拉伸截图不算DPI证据。
- 下载由用户明确选择的空测试目录执行；HLS/保护/失效资源单独记录状态，不绕过DRM。
