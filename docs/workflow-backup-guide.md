# 完整工作流、备份与历史整理

适用于 v1.0.0-rc.1。只支持 Amazon；真实 AI 仍逐次明确授权，未配置时使用本机 Mock。

## 从商品到营销成果

1. 启动工作台并配对扩展，正常打开 Amazon 商品页面，明确同意采集并保存。
2. 在商品库搜索、筛选或分组。详情的「素材」页查看图片来源、尺寸和公开视频状态；只能下载允许的公开资源，文件目录由用户选择。
3. 在详情进入商品 AI 分析，或「加入竞品对比」选择 2–5 个商品。对比内容是保存时资料，不是实时价格；币种不同不排列价格高低。
4. 从详情「选择 AI 模板」或「内容创作」，商品 ID 与 ASIN 自动带入。对比方案已保存 AI 结论后，可选择其中商品「引用结论创作」。
5. 内容方案保存商品、模板、竞品快照。商品分析作为未验证推断引用；不会把它变成页面事实，也不会冒充评论正文分析。
6. 展开「选择创作参考素材」，勾选并明确保存。这里只保存原商品快照的安全 URL；模型仅收到选中数量，不发送媒体 URL 或文件。未保存选择会阻止生成，允许取消。
7. 生成、逐项编辑、比较候选版本，导出 Markdown / TXT / JSON 或文字 ZIP。内容包含来源与生成参数，默认不复制媒体文件。

「来源与更新状态」区分资料、商品分析、模板和竞品结论。商品或模板更新后，不自动改变旧方案，也不覆盖人工修改。「用最新资料创建新方案」需要确认，生成新的独立方案。原商品删除后，内容和对比快照、分析及历史仍可查看；不会偷偷换成另一个同名商品。分组、标签和收藏调整不会制造资料过期提醒。

创作偏好可保存。首次没有创作偏好时复用已有商品分析偏好；之后各自明确保存，不反复覆盖。

## 完整业务备份

导航「设置与备份」→「导出完整业务备份」。覆盖五个业务文件：商品（分组/标签/全部分析历史）、竞品对比、用户自定义模板、内容方案及其快照/参考素材/历史、AI 请求与用量。内置模板随程序提供。可明确勾选附带此浏览器的商品库、分析、创作偏好及内置模板收藏。

不包含 API Key、Cookie、配对令牌、Windows DPAPI 配置、浏览器会话、未保存编辑草稿或实际素材文件。用量的单向请求指纹用于防重复计费，不是认证凭据。备份可能包含业务文案、公开商品 URL 和用量，分享前仍应自行检查内容。

恢复时选择 JSON →预览数量、引用、冲突与容量→选择安全冲突策略→二次确认。跳过/保留策略都保留已有同 ASIN 商品的人工分析及历史，不静默覆盖。同 ASIN、不同旧 ID 的快照保持原 ID，并提示当前资料无法一一对应。浏览器偏好需要单独勾选才恢复。超过上限、格式错误、未知字段、恶意 URL、引用不匹配或预览后资料变化，取消写入并提示重新预览。

完整备份最多 100 MiB，单业务文件最多 25 MiB。恢复使用五文件独占锁与暂存事务日志；异常发布回滚，重启时先恢复事务再读取。发现损坏日志或不安全目录，保留原文件并阻断操作；不要删除暂存日志来强行继续，应先停止程序并复制整个用户目录供诊断。

商品库、对比、模板与内容的独立备份入口继续保留，范围各自明确。媒体下载到用户自选目录，需另行备份。保留 Key、配对与 Windows 加密设置的精确本机回退副本，应在停止服务后复制完整 `%LOCALAPPDATA%\ProductSpy`；此副本含敏感资料，不作为普通可分享业务备份上传。

## 历史容量管理

商品分析、竞品分析、用户模板和内容方案都可展开「历史容量管理」，查看数量、字节占用和受保护节点。45/50 个版本提示接近上限，达到 50 时拒绝新生成/编辑，不自动删历史，不先收费再发现无法保存。

选择指定旧版本→导出历史归档→确认文件实际保存→明确勾选二次确认→清理。当前采用版本、初始恢复节点和现有恢复来源受保护；人工编辑没有自动选择或删除。归档凭证只对当时实体/完整内容/选定版本有效，30 分钟过期；资料改变需重新归档。签名凭证不写入可分享归档文件。

清理后，仍保留的节点记录已归档父版本 ID 与归档摘要。归档含完整实体快照及所选历史，可作为人工恢复参考；**历史归档不是可直接覆盖同 ID 实体的恢复文件**。现有安全导入仍跳过同 ID。需要自动完整恢复时，请事先导出完整业务或该模块备份，并在独立用户目录恢复，不要修改正在使用的数据文件。

自定义模板、内容方案和对比方案最多各 200 个；设置页 180 个起预警。先导出和整理，再明确删除不需要的实体，程序不会因满容量而删除用户资料。

## 更新与回退

停止旧版、保留业务备份及私人本机回退副本、新包完整解压到独立目录、运行新版，用户目录不变。v0.7.0→v0.8.0 不重写原业务文件、不清空 ID、历史、偏好和配对。

新版保存了参考素材或归档来源等新增字段后，旧程序的严格 schema 可能拒绝读取。回退必须使用升级前副本和原便携包，不能用旧程序直接写回新版用户目录。具体实测和限制见 [Phase 19 升级说明](phase19-upgrade-notes.md)及[验收报告](phase19-validation.md)。

候选版复测 v0.8.0 / v0.7.0 与更早实际便携包升级，保留旧版本原字节及完整业务引用；最终结果见 [Phase 20](phase20-validation.md)。旧程序回退仍需使用升级前私人副本。
